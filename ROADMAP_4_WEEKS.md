# 4-Week Beginner Plan (Python QA Automation)

## Week 1

- Install Python, Git, VS Code
- Learn terminal basics and virtual environments
- Finish `project_1_unit_pytest`
- Push first version to GitHub

## Week 2

- Learn HTTP basics: methods, status codes, JSON
- Finish `project_2_api_pytest`
- Add 3-5 additional API tests by yourself

## Week 3

- Learn browser automation basics
- Finish `project_3_ui_playwright`
- Add at least 2 new negative UI tests

## Week 4

- Improve README in each project (what tested and why)
- Record short demo videos or GIFs (optional)
- Update CV and internship form with GitHub links
