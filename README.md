# QA Python Internship Portfolio

Портфолио из 3 учебных проектов по автоматизации тестирования на Python.

## Проекты

1. `project_1_unit_pytest`
- Unit-тесты на `pytest`
- Фикстуры, параметризация, позитивные и негативные проверки
- Проверка бизнес-логики для калькулятора и корзины

2. `project_2_api_pytest`
- API-тесты для локального сервиса на `FastAPI`
- Проверка `/health`, создания задач, получения несуществующей задачи и изменения статуса
- Проверка status code и response body

3. `project_3_ui_playwright`
- UI-автотесты формы (Python + Playwright)
- Паттерн `Page Object`
- Проверка успешной отправки формы и валидации невалидного email

## Что демонстрирует портфолио

- Умение проектировать тест-кейсы для разных уровней: unit, API, UI
- Навыки работы с `pytest`, `requests`, `FastAPI`, `Playwright`
- Базовую структуру автотестового проекта и читаемые проверки

## Стек

`Python`, `pytest`, `requests`, `FastAPI`, `Playwright`, `Page Object`, `Git`, `GitHub`
