# QA Python Internship Portfolio (Beginner)

This folder contains 3 training projects for an internship in Python test automation.

## Projects

1. `project_1_unit_pytest` - unit tests with `pytest` (fixtures, parametrization, edge cases).
2. `project_2_api_pytest` - API tests for a local FastAPI service.
3. `project_3_ui_playwright` - UI tests (Python + Playwright) for an internship form.

## Recommended learning order

1. Finish Project 1.
2. Move to Project 2.
3. Finish with Project 3.

## What to install first (Windows)

1. Install Python 3.11+ from official website.
2. Install Git for Windows.
3. Optional but useful: VS Code.

## How to publish this folder to GitHub

1. Create empty repository on GitHub (for example: `qa-python-portfolio`).
2. Open PowerShell in this folder and run:

```powershell
git init
git add .
git commit -m "Initial QA portfolio: unit, API and UI automation projects"
git branch -M main
git remote add origin https://github.com/<your_username>/qa-python-portfolio.git
git push -u origin main
```

If GitHub asks for authentication, use your browser flow or personal access token.
