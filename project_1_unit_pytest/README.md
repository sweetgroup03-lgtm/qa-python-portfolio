# Project 1: Unit Tests with Pytest

## Stack

- Python
- pytest

## What this project demonstrates

- Basic test design
- Parametrized tests
- Fixtures
- Positive and negative checks

## Run

```powershell
cd project_1_unit_pytest
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pytest -v
```
